## 1. 功能概述

E-cology 的表单建模（formmode）是一套**无代码表单/模块搭建平台**，核心能力：

| 能力域 | 说明 |
|---|---|
| 表单设计器 | 基于 wijmo Spread 的「Excel 式」表格布局设计器，支持拖拽字段、合并单元格、明细表、公式计算、样式设计 |
| 字段体系 | 8 类 UI 组件 + 文本子类型 + 浏览框 20+ 子类型 + 系统内置字段 |
| 数据建模 | 设计期自动建物理主表/明细表，字段直接映射数据库列 |
| 校验体系 | 必填、正则、导入预设校验（电话/身份证/邮箱等）、唯一性、数据库唯一索引、自定义 SQL/公式 |
| 权限体系 | 三层权限：模块/数据权限、字段级权限（可见/可编辑/必填）、数据分享（共享）+ 按钮/操作权限 + 布局级权限 |
| 流程集成 | 表单挂接流程节点，节点级字段权限，模块↔流程互操作（触发流程/流程写回），字段触发联动 |
| 版本管理 | 布局版本（`modehtmllayout.version`）+ 模板（.wef）导入导出 + 应用/模块整体导入导出框架 |
| 运行期 | 建模表单可作为独立模块页面，也可嵌入流程发起/审批/查看页 |

**架构分层（前端）**：

## 11. 对 SpringBlade 落地的参考要点

> 项目已有平行实现 `D:\project\springbladeandreact\SpringBlade\blade-formmode` 与既有文档 `doc\md\表单建模功能分析报告.md`、`doc\md\泛微E9表单建模字段属性配置详解.md`。本章仅列源码调研中发现的**易错点/对齐点**：

1. **字段类型编码必须做映射层**：ecology 原生 `fieldhtmltype`（1–6，`FieldValue` 权威）与新版设计器 UI 编码（1–8，`fieldTypes.ts`）不是一套；互通时用 `mode_fieldtype` + `FieldTypeComInfo` 作为字典源。
2. **布局序列化可对标**：`modehtmllayout.datajson`（Base64+JSON，`formdesign/eattr/etables/ec[]`）+ `pluginjson`（wijmo sheet JSON）。若 SpringBlade 采用 SpreadJS/Luckysheet，可参考 `doc\md\SpreadJS核心API接口清单.md` / `Luckysheet核心API接口清单.md`。
3. **权限三态 + 布局级**：`ISVIEW/ISEDIT/ISMANDATORY` 三态与 `layoutid/layoutlevel`（显示/新建/编辑/监控多布局分别授权）是核心设计，SpringBlade 侧字段权限需覆盖「布局维度」。
4. **校验分层**：预设正则（impcheck/checkexpression）+ 唯一性（modeformverify）+ 数据库唯一索引 + 自定义 `IDoSubmitCheck`，四层并存。
5. **流程集成双向**：模块触发流程（`mode_triggerworkflowset`）与流程节点写回模块（`mode_workflowtomodeset`）是两条独立链路。
6. **导入导出包结构**：`{data.xml, dataForm.xml, dataSetForm.xml, browser.xml, workFlowSet.xml, file.xml}` 可作为 SpringBlade 表单/模块迁移格式的参考。
