# 泛微 E9 跨模块风险登记册（P0/P1/P2 统一治理）

> 合并自 4 份深度分析：`内容引擎 DocEngine`、`公文 odoc`、`流程 workflow`、`分权 ManageDetach`。
> 覆盖模块：doc / odoc / workflow / 分权；覆盖维度：安全 / 架构 / 数据 / 性能 / 命名 / 一致性。
> **只读分析结论的归类整理，未修改任何代码。** 所有证据路径均为绝对路径，行号对应 `E:\project\ecology\ecology\src`。

---

## 0. 严重度与类别定义

| 严重度 | 含义 | 整改要求 |
|---|---|---|
| **P0** | 越权 / 注入 / 匿名可达 / 数据外泄 | 立即整改，纳入最高优先级 |
| **P1** | 逻辑错误 / 判定不一致 / 性能热点 / 架构割裂 | 排期整改（1~2 个迭代内） |
| **P2** | 命名 / 死代码 / 可读性 / 硬编码 | 顺手清理，不阻塞业务 |

| 类别 | 说明 |
|---|---|
| SEC 安全 | 权限绕过、注入、越权、未授权访问 |
| ARCH 架构 | 分层混乱、技术栈割裂、死代码、设计器实现 |
| DATA 数据 | SQL 拼接、表结构、ORM、字段一致性 |
| PERF 性能 | 读扩散、缓存缺失、巨型类、N+1 |
| NAME 命名 | 拼写、路径规范、注释、国际化硬编码 |
| CONS 一致性 | 判定逻辑、缓存失效、重复实现、路由重复 |
