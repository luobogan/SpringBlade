# 去 `wf_*` 表改造 · 开发计划

> 配套分析文档：`doc/md/Flowable8承接台账模块-去wf_表改造分析.md`
> 目标：以 **Flowable 8.1.0-SNAPSHOT（本地源码构建）** 重新实现台账模块，**不保留任何 `wf_` 前缀表**，引擎成为唯一事实源。
> 本文为开发派活与进度跟踪用，按分析文档 §七（分期）、§十六（前端）、§十七（任务总表）拆解。

## 三、后端开发任务（`springBlade` 分支，T-1 ~ T-14）

> 来源：分析文档 §七 分期 + §17.4 任务总表。

### P1 定义期下沉（低风险，可独立交付）
- **T-1** 依赖扫描：`wf_*` 实体在前后端/上下游的引用面 → 产出影响清单
- **T-3** BPMN 扩展 schema 定稿 + 往返保真测试（V7/V13）→ 产出 schema + 测试（**前端前置**）
- **T-5** 定义期语义回填（节点/出口/操作者/权限/超时 → BPMN 扩展）+ 双轨对账（只读告警）→ 迁移脚本 + 对账

### P1 配套数据模型
- **T-2** 数据模型定稿（含 D6、D8）→ DDL 终稿
- **T-6** `ACT_*` 加列 + 租户复合索引（§十一 DDL）→ DDL 脚本
- **T-7** 实例级回填（含 `TENANT_ID_`）+ 校验（V27）→ 回填脚本

### P3 会签切换（🔴 最高风险，需 P2 门禁）
- **T-8** 超时链路改造：扫 `DUE_DATE_` + 修 R4 + 多副本治理（D9）→ 代码 + 调度方案
- **T-9** 审批日志迁移到 `ACT_HI_COMMENT`（含 D8）→ 迁移脚本
- **T-10** 接口改造：逐个盘点筛选能力（D10）→ 接口实现
- **T-11** 权限/操作者改读 BPMN 扩展（A4）→ 代码

### 收口验证
- **T-12** 并发与性能压测（V23–V26）→ 压测报告
- **T-13** 多租户隔离验证（V19–V22）→ 验证报告
- **T-14** 存量 `wf_*` 退役（保留归档与 `wf_migration_map`）→ 退役清单

**关键依赖链**：
- 定义链：`T-3 → T-5`
- 后端主链：`T-2 → T-6 → T-7 → T-10`
- 两条链并行；`T-12 / T-13` 收口验证；`T-14` 最后退役。
